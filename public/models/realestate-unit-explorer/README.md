# 모델 자산 계약 (realestate-unit-explorer)

현재 GLB 없음: 절차적 모델 사용. 교체 방법은 `components/industry/RealEstateUnitExplorer/README.md` 참고.
GLB 를 이 폴더에 넣고 `config.ts` 의 `MODEL_ASSET.url` 을 `/models/realestate-unit-explorer/<file>.glb` 로 지정한다.
노드 이름 규칙(`F_<층>` > `U_<id>`, `ROOF`, `C_<층>`)은 `ASSET_CHECKLIST` 와 같다. `units.sample.json` 은 매물 JSON 형식 샘플(데모 값).
